# Миграция сохранений Doom II

`migrate_saves.py` переводит старые `doomsav*.dsg` Win32-порта (`version 110`)
в формат `AntiDoom save 2`. Положение игрока, инвентарь, время, счётчики и записи
состояния карты сохраняются; меняются выравнивание записей, заголовок и контрольные суммы.

Нужны Python 3 и тот же GCC/ABI, которым собран порт. `save_layout.c` автоматически
компилируется во временной папке, чтобы получить действительные размеры структур.

Из корня игры:

```powershell
python src/tools/migrate_saves.py --wad wad/DOOM2.WAD --save-dir . --dry-run
python src/tools/migrate_saves.py --wad wad/DOOM2.WAD --save-dir .
```

Для GCC вне PATH добавьте `--compiler E:/Soft/Strawberry/c/bin/gcc.exe`.

Указывайте именно тот Doom II WAD, с которым созданы сейвы: старый формат не
содержит идентификатора WAD. Скрипт проверяет размеры и границы записей, теги
секторов/линий выбранной карты, индексы состояний, типов объектов и секторов,
наличие игрока и конечные маркеры. Все слоты проверяются до замены первого файла.

Оригиналы и манифест SHA-256 сохраняются в `save-backups/before-v2-<дата>/` внутри
папки сейвов. Замена каждого файла выполняется через временный файл. Уже
обновлённые сейвы пропускаются. Для восстановления скопируйте оригиналы из
резервной папки; читать их нужно старой совместимой сборкой порта.
